# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [3.6.0] — 2026-07-14

### Added
- **Watch Folder: файлы без расширения** — новая настройка `WATCH_FOLDER_PARSE_NO_EXTENSION` (UI-чекбокс "Parse files without extension"). Когда включена, файлы без расширения проходят фильтр расширений и импортируются как DICOM.
- **Watch Folder: контролируемый размер батча** — новая настройка `WATCH_FOLDER_BATCH_SIZE` (по умолчанию `100`). Очередь из тысяч файлов разбивается на батчи и обрабатывается порциями, не блокируя роутер.
- **Watch Folder: быстрое сканирование больших папок** — вынесена «тяжёлая» проверка стабильности файла (0.2s sleep) из фазы сканирования в фазу импорта. Сканирование 20 000 файлов теперь занимает секунды вместо часов.
- **Watch Folder: graceful re-queue** — файлы, которые ещё не готовы к импорту, возвращаются в очередь вместо безвозвратного пропуска.

### Fixed
- Исправлен синтаксис SQL-запроса в `DatabaseManager.update_dmis_task` (некорректный f-string с тройными одинарными кавычками).
